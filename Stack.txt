Backend
Language: Python 3.12
Framework: FastAPI
Agent framework: Google ADK (Python)
Model (main): Gemini 3.6 Flash
Model (cheap tasks): Gemini 3.5 Flash-Lite
Model access: Gemini Developer API (free tier, simple API key — no billing setup needed)
Embeddings: Gemini embedding model, via same free API


Database
Database: Neon (free managed Postgres) + pgvector extension
One single database for everything — sessions, learner memory, concepts, chunks, vectors. No second vector database.
ORM: SQLAlchemy
Migrations: Alembic

File storage
PDF uploads: Google Cloud Storage (free tier is enough)
Background jobs (PDF processing, memory updates)
Queue: Google Cloud Tasks
Worker: second Cloud Run service that processes the queue

Auth
Login: Firebase Authentication (free)

Frontend
Framework: React + JavaScript + Vite
Styling: Tailwind CSS + shadcn/ui
Graph view: Cytoscape.js
Served as static files from the same backend — one URL, nothing extra to deploy
Deployment
Hosting: Google Cloud Run (2 services: api + worker), scales to zero = free when idle
